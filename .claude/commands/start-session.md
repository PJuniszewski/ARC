1. Read `memory/MEMORY.md` — routing table for cross-session knowledge
2. Read `memory/active.md` — current WIP, blockers, recent completions
3. Read `CLAUDE.md` — operating rules and guardrails
4. Read `MEMORY.md` (root) — project state, open questions, priorities
