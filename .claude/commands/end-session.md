# End Session

Use at the end of meaningful work to ensure session continuity.

## Checklist

1. **Update `memory/active.md`**
   - Move finished work to "Recently Completed" with commit ref and lesson learned
   - Add any new WIP items discovered during work
   - Update blocked items and pending decisions

2. **Update data files if new learnings emerged**
   - New gotcha? → `memory/gotchas.md`
   - New architecture pattern or decision? → `memory/architecture.md`
   - New spec fact? → `memory/spec-knowledge.md`
   - New research insight? → `memory/research.md`

3. **Clear scratchpad**
   - If `memory/scratchpad.md` was used, clear intermediate results

4. **Update root MEMORY.md if project state changed**
   - New open questions
   - Changed priorities
   - Shifted design direction
   - New risks identified

5. **Propose summary**
   - What was accomplished
   - What's next
   - Any unresolved blockers

## Rule

Every session should leave the next session better informed than this one started.
