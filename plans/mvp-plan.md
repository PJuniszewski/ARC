# MVP Plan

## Goal

Prove ARC can work end-to-end with a narrow slice.

## MVP scope

- local archive layout
- manifest generation
- content-addressed blobs
- source units
- claims
- inspect
- verify
- diff

## Out of scope

- full graph mode
- advanced executable layers
- full OCI distribution
- advanced merge

## Milestones

1. finalize format skeleton docs
2. create fixture examples
3. define CLI behavior
4. implement build/inspect/verify/diff prototype
5. run first evaluation harness
