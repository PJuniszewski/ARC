# Market Landscape

## What already exists

### Agent memory systems
These help agents remember over time, but usually focus on runtime memory, not portable archive artifacts.

### Checkpoint systems
These preserve state snapshots, but they are not the same as portable semantic context packages.

### Retrieval stacks and vector DBs
These help find context, but do not solve provenance, artifact portability, or durable semantic packaging.

### Repo context products
These index codebases well, but often remain proprietary, runtime-bound, or non-portable.

---

## What seems missing

A practical, portable, verifiable artifact for agent context that combines:

- semantic structure
- versionability
- trust metadata
- selective load
- diffability

That is the gap ARC is trying to explore.
