# Semantic Model

## Objective

The semantic layer is what makes ARC more than a glorified file bundle.

It should carry portable meaning, not just bytes.

---

## Core object types

### SourceUnit
Represents an addressable source fragment.

Fields:
- `id` — deterministic, content-based
- `resource_id` — parent resource
- `kind` — section | function | paragraph | frontmatter
- `content` — raw text
- `span` — (start_line, end_line)
- `content_digest` — SHA-256 of content

### Claim
An atomic assertion extracted from source or produced by an agent.

Fields:
- `id` — unique identifier
- `text` — the claim content
- `kind` — fact | assertion | requirement | definition (fine-grained label)
- `claim_type` — **observation | decision | uncertainty | dependency | conflict** (coarse category)
- `source` — who produced this: agent ID, `"human"`, or `"builder"` (auto-extraction)
- `timestamp` — ISO8601 when produced
- `evidence` — list of EvidencePointers
- `confidence` — 0.0–1.0
- `status` — observed | derived | verified | deprecated | contested
- `derived_from` — source_unit_id for simple provenance
- `references` — IDs of related claims (conflict claims reference the two disagreeing decisions)

See [`claim-schema.md`](../claim-schema.md) for full type semantics and usage rules.

### Decision
A structured record of rationale, options, and chosen path (ADR-style).

Fields:
- `id`
- `title`
- `context`
- `options`
- `decision`
- `consequences`
- `evidence`
- `status` — proposed | accepted | superseded | rejected
- `source` — who produced this
- `timestamp`

A `Claim` with `claim_type="decision"` is a lightweight decision (one-liner). A `Decision` is the full structured form.

### EvidencePointer
Links semantic objects back to source units.

Fields:
- `source_unit_id`
- `span` — optional (start_line, end_line)
- `weight` — optional relevance weight

---

## Claim types

| Type | When to use | Confidence meaning |
|------|------------|-------------------|
| `observation` | Factual statement grounded in source. Must have evidence. | How certain the fact is |
| `decision` | Judgment made by agent or human. Evidence = what informed it. | Agent's conviction |
| `uncertainty` | Open question needing investigation. | Should be low (0.0–0.3) |
| `dependency` | Blocker or prerequisite for further work. | How certain it blocks |
| `conflict` | Generated by `arc merge` only. Two agents disagree. | Similarity score between conflicting claims |

---

## Important modeling rule

A summary without evidence should never pretend to be a verified fact.

The model distinguishes:

- extracted fact (`claim_type: observation`, `status: observed`)
- inferred summary (`claim_type: observation`, `status: derived`)
- accepted decision (`claim_type: decision`, `status: verified`)
- unresolved hypothesis (`claim_type: uncertainty`)
- contested claim (`status: contested`)

---

## Status values

For claims:
- `observed` — extracted from source
- `derived` — inferred, not directly observed
- `verified` — confirmed by human or downstream agent
- `deprecated` — superseded by newer information
- `contested` — flagged as potentially wrong or conflicting

For decisions:
- `proposed`
- `accepted`
- `superseded`
- `rejected`
